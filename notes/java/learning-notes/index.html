Java 学习笔记总目录

这套笔记记录 Java 从基础语法到 JVM、集合、IO 和并发编程的学习过程，现已按主题拆分，方便查找与持续维护。

专题目录

  1. Java 语法基础 — 整理 Java 的标识符、数据类型、类型转换与常用运算符。
  2. Java 面向对象基础 — 从类与对象出发，整理 this、super、final、封装、构造器和继承。
  3. Java 面向对象进阶 — 整理多态、重载与重写、初始化块、抽象类、接口、内部类和枚举。
  4. JVM 内存与垃圾回收 — 整理 JVM 基础、类加载、栈与堆，以及对象、数组和垃圾回收机制。
  5. Java 常用类、日期与正则 — 整理 System、Runtime、Object、字符串、数学、日期和正则表达式相关 API。
  6. Java 泛型与集合 — 整理泛型，以及 List、Set、Map、队列等 Java 集合体系。
  7. Java 异常处理 — 整理 Java 异常体系、捕获、抛出以及自定义异常。
  8. Java IO 与文件操作 — 整理 File、字节流、字符流、缓冲流、转换流和序列化。
  9. Java 多线程基础与同步 — 整理线程创建、生命周期、同步、锁、阻塞队列、死锁和线程通信。
  10. Java 线程中断与 LockSupport — 深入整理线程启动与终止、中断标记、LockSupport，以及 sleep、wait、join。
  11. Java 内存模型与 volatile — 整理 Java 内存模型，以及 volatile 的可见性与禁止指令重排序语义。
  12. Java 单例设计模式 — 整理饿汉式、懒汉式、双重检查锁和静态内部类等单例实现。
  13. 从 Collections.sort 到 TimSort：源码阅读 — 沿调用链理解 Collections.sort、List.sort、Arrays.sort 和 TimSort。
