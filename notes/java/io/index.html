InputStream 和 Reader

读取文件

对比点 按字节读 (InputStream) 按字符读 (Reader)
读取单位 字节 (byte) 字符 (char)
是否解码 否，需手动 new String(bytes, charset) 是，Reader 内部解码
中文表现 拆成 3 个负数字节 完整显示为“和”、“好”
是否可能乱码 不会（因为没解码） 可能（如果编码不一致）
适用场景 二进制文件（图片、音频等） 文本文件（txt、csv 等）
特性 InputStream InputStreamReader
读取单位 字节（byte） 字符（char）
处理内容 原始二进制数据 文本（字符）
是否涉及编码 ❌ 不处理编码 ✅ 需要指定字符集（如 UTF-8）
常见子类 FileInputStream, BufferedInputStream 无子类，通常配合 BufferedReader 使用
使用场景 图片、音频、网络、ZIP、任何二进制 读取文本文件、控制台输入、网络文本
示例 is.read() 返回 int（0~255） reader.read() 返回 int（一个字符）
代码 类型 抽象级别 读取单位 适用场景 备注
InputStream is = new FileInputStream(file) FileInputStream → InputStream 字节流 字节 (byte) 读 二进制数据（图片、音频、网络流） 不关心编码，直接读原始字节
FileReader fr = new FileReader(file) FileReader → Reader 字符流 字符 (char) 读 文本文件 使用 平台默认编码，可能乱码
Reader rea = new FileReader(file) Reader（接口） 字符流接口 字符 (char) 同上，但更灵活 可指向任意 Reader 实现，如 BufferedReader
