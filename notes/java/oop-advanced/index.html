Java 面向对象进阶

整理多态、重载与重写、初始化块、抽象类、接口、内部类和枚举。

多态

​ 子类的实例化对象赋值给父类的引用类型变量，在运行的时候又表现出子类的形态，一个父类可以有多个子类

​ 在调用 Person 中的 eat 对象，在调用 Person 中的方法中，一会是 stu 的方法，一会是 teacher 中的内容，执行的内容不确定，只有在运行的时候，是什么样的对象，才执行什么样的方法，一种代码表现出了多种形态！

方法覆盖（重写）

（重写）指子类重写父类的方法，使得子类对象在调用该方法时，执行的是子类的实现，而不是父类的实现。这是动态绑定（Dynamic Binding）的一个典型例子

方法重载

​ 方法重载是指在同一个类中定义多个同名方法，但这些方法的参数列表不同（参数的数量、类型或顺序不同）。

​ 重载与返回值无关，只看方法名和参数列表

​ 方法重载是静态绑定的一个典型例子，即在编译时确定调用哪个方法

多态与方法重载的区别

特性 多态（方法覆盖） 方法重载
定义 子类重写父类的方法 同一方法名，不同参数列表
绑定类型 动态绑定（运行时） 静态绑定（编译时）
参数列表 必须相同 必须不同
返回类型 必须相同或兼容 可以不同
使用场景 子类需要改变父类方法的行为 提供多种方法实现，根据参数选择

初始化块和构造器

​ 初始化块先于构造器执行，系统可以同样使用初始化块来进行对象的初始化操作

​ （Static）静态初始化块是类相关的，系统在类初始化阶段时执行静态初始化块，而不是在创建对象时才执行。因此静态初始化块总是比普通初始化块先执行。

运行顺序：构造器总是最后运行，先加载通用的，再调用个性化的

初始化代码块是初始化实例对象的，与全局变量一样的优先级

抽象类

  • 抽象方法与抽象类必须使用 abstract 关键字进行修饰
  • 有抽象方法的类必须被定义成抽象类。
  • 抽象类里面可以没有抽象方法。

1、 抽象类与抽象方法必须使用 abstract 关键字进行修饰，抽象方法不能有方法体。

2、 抽象类不能被实例化。即使抽象类不包含抽象方法，也不能被实例化。

3、 抽象类可以包含 field、方法、构造器、初始化块、内部类 5 种成分。

包含抽象方法的类，只能被定义成抽象类
