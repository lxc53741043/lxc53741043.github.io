字符串比较相等

非基本类型进行 = = 操作时候，比较的是内存地址

str1.equals(str2)

  • 功能：用于比较两个字符串的内容是否相同。
  • 行为：equals() 方法会逐个字符比较两个字符串的内容。如果两个字符串的长度相同，并且每个对应位置的字符都相同，则返回 true；否则返回 false。
  • 用途：当需要比较两个字符串的 内容 是否相同时，应该使用 equals() 方法。

str1 == str2

  • 功能：用于比较两个字符串对象的 内存地址 是否相同。
  • 行为：== 运算符会检查两个字符串变量是否指向同一个对象。如果两个变量指向同一个对象，则返回 true；否则返回 false。
  • 用途：== 通常用于比较对象的引用是否相同，而不是比较内容。在字符串比较中，如果需要比较内容，应该使用 equals()。
