  • 第一次取 left = Bob, right = Cindy
    Bob.compareTo(Cindy) → 30 vs 20 → -1 → Bob 更大 → Bob 先输出
  • 第二次取 left = Alice, right = Cindy
    Alice.compareTo(Cindy) → 25 vs 20 → -1 → Alice 更大 → Alice 输出
  • 最后只剩 Cindy → 结束

最终顺序：[Bob, Alice, Cindy]

8. 总结一句话

TimSort（或任何排序器）在算法需要比较两个元素时，
随机/策略性地把这两个元素作为 this 和 o 传给你写的 compareTo，
你只需要回答“谁大谁小”，至于“先挑哪两个”完全由排序器内部决定。
