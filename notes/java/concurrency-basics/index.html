成员方法

成员方法

方法签名 功能说明 补充说明 / 示例
String getName() 返回当前线程的名字 名字默认格式 Thread-X(默认从 0 开始)
void setName(String name) 设置线程名称 多次调用有效；调试时便于识别
如果给线程设置名字，可以用 setName 方法或者是在类里面重写父类 Thread 构造函数方法去调用构造函数重写
static Thread currentThread() 获取当前代码所在线程对象 常用于日志：Thread.currentThread().getName() 当 JM 虚拟机启动之后，会自动的启动多条线程
其中有一条线程就叫做 main 线程
他的作用就是去调用 main 方法，并执行里面的代码
在以前，我们写的所有的代码，其实都是运行在 main 线程当中
static void sleep(long millis) 让当前线程休眠指定毫秒 需捕获 InterruptedException
void setPriority(int newPriority) 设置线程优先级（1–10） 1 = 最低，5 = 常规，10 = 最高；调度仍由 OS 决定 设的 1~10 只是“建议值”，真正决定谁先谁后的是操作系统调度器；
Java 只能把建议递交给 OS，不能保证绝对按优先级顺序执行。
设置优先级，不是说 A 的优先级高 A 一定能抢到，而是 A 的优先级高，A 抢到的概率大
final int getPriority() 获取线程优先级 默认继承创建者优先级
final void setDaemon(boolean on) 标记守护线程（true）或用户线程（false） JVM 只剩守护线程时立即退出
必须在 线程启动前 调用 setDaemon(true/false)，否则会抛 IllegalThreadStateException
public final Boolean isDaemon（） 判断当前线程是否为守护线程 当 所有非守护线程 结束，JVM 立即退出，守护线程被强制终止
后台监控、日志、垃圾回收、心跳线程等 非关键任务
public static void yield() 提示调度器让出 CPU 只是建议，不保证立即生效
public final void join() 等待该线程结束 可重载 join(long millis) 指定最大等待时间
