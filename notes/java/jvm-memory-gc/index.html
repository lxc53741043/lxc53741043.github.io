答：会，没有变量引用它，

内存机制和数据类型在内存中的情况

栈

存放的是局部变量，生命周期仅限于方法的执行过程

堆

存放的是所有 new 出来的东西

在类里面的实例变量存放到堆里面

静态变量存放到方法区里面

基本数据类型内存

变量的值直接存储在变量身上

引用数据类型内存

对象本身存到堆，变量存的是这个对象的地址值

​ 在创建 Student 对象时，实际创建了两个东西，一个是栈内存中的变量 stu，存储的是类 Student 对象的地址值。一个是堆内存（数据区域）中的 Student 对象本身。在堆内存中的对象本身中，自身的属性变量（Field）并不是存放在栈内存中的，同样也是存放在堆内存中的。对于基本数据类型的变量（Filed）来说，变量存放的是具体的值，对于引用数据类型的变量（Field）来说，存放的同样是该类型指向的具体类型的地址值。引用变量都是指向堆内存里的对象。引用变量与 C 语言里的指针很像，都是存储一个地址值。

一维数组内存分配

赋值实际上是把对象在堆内存中的物理地址值赋给栈内存中的变量；

变量存储的是物理地址；

Java 中每创建一个对象，都把对象放在堆内存中；

java 堆内存是数据运行区，当运行 main 方法时，首先方法去执行，方法执行时会开辟一个栈内存

内存 对象的创建

数组对象被存储在堆内存中（heap），而引用该数组对象的数组引用变量如上例中的 a 变量，则被存储在栈内存中（stack）。

基本数据类型数组与引用数据类型数组的差别

基本数据类型数组在初始化时，在堆内存中的数组对象里面已经初始化好数据值并且进行存放。引用数据类型的数组在初始化时，在堆内存中的数组对象实际存放的是引用数据类型的引用变量

1. 直接定义的 String str = “a” 是储存在常量存储区中的字符串常量池中；

String str = new String(“a”)是存储在堆中

2. 常量池中相同的字符串只会有一个，但是 new String()，每 new 一个对象就会在堆中新建一个对象，不管这个值是否相同；

String a = “a” String b = “a” a b 都指向字符串常量池中的“a”, 所以 a == b 为 true;

String a = new String(“a”) String b = new String(“a”); 是会在堆中创建两个对象 new String() “a”是常量池中的”a”，这两个对象的值都为 a, 所以 a == b 返回 false；a.equals(b)返回 true;

3. String a = “a”在编译阶段就会在内存中创建；
